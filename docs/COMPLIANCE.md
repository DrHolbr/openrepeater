# Repeater identification and control

Source: eCFR Part 97 texts retrieved November 6, 2026. eCFR is authoritative but unofficial and is not the official legal edition. The fetched sections include January 14, 2026 amendments. The FCC FAQ updated April 21, 2017 does not control over the current rule text. This file is not an FCC certification, a legal opinion, or a statement that the station complies on the air. No station grant, trustee, control operator, location, privilege, or frequency is inferred from any call sign, including W8DRH.

A disconnected Pi can show a generated configuration file and a rendered page. Multiplying the configured minute count by 60 is arithmetic on that integer. It is not evidence that SvxLink emitted an identification event. SvxLink 26.05 `src/svxlink/svxlink/Logic.tcl` calls `checkPeriodicIdentify` once a minute. A short identification is considered when `(hour * 60 + minute) % SHORT_IDENT_INTERVAL` is 0, and it returns without sending if fewer than `min_time_between_ident` (120) seconds have passed. This repository does not execute that procedure.

Status words: `configuration-verified` means a generated file or derived arithmetic on that file was checked. It is not SvxLink event timing. `software-proven` means a cloud test executed the named behavior. `operator-gate` needs a person and a procedure. `hardware-unverified` needs the radio, the running controller, or a measurement. `not-this-architecture` means the cited duty is conditional and this setting is a different function. The native page gate on `adda19c` showed complete HTML. It did not complete FCC gates, preset translation, or handler execution.

## What the page gate did and did not close

Installed `adda19c` reloaded the nine pages. Identification and courtesy closed, the long identification controls were present, and the empty audio library did not fatal. That does not verify SvxLink event timing, an end-of-communication identification, spoken English audio, or a transmitter unkey. A later runtime test has to execute the controller. No service is unmasked by the page gate. The functional-test token in the following commit is for review. It is not a deployment performed from here, and it does not mark the FCC rows complete.
