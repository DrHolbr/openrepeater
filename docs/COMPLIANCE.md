# Repeater identification and control

Source: eCFR Part 97 texts retrieved November 6, 2026. eCFR is authoritative but unofficial and is not the official legal edition. The fetched sections include January 14, 2026 amendments. The FCC FAQ updated April 21, 2017 does not control over the current rule text. This file is not an FCC certification, a legal opinion, or a statement that the station complies on the air. No station grant, trustee, control operator, location, privilege, or frequency is inferred from any call sign, including W8DRH.

A generated minute count is not, by itself, an identification event. On `97077d5` the native process log recorded `Sending long identification` and `Playing long CW ID` at 10:00 PM EST, then `Sending short identification` and `Playing short CW ID` at 10:10 PM EST, and a clean exit. That is the running timer. It does not decode the call sign, the CW characters, or an emission. A passive loopback capture on UDP port 17002 held 501 datagrams and 346986 nonzero payload bytes. Those bytes were not decoded. `repeater_down` was not invoked by a receiver, so end-of-communication identification remains unverified. The tclsh harness now follows `locale.tcl` `spellWord`, which plays `Default` `phonetic_<letter>` clips for the configured word. That trace is the procedure, not the Pi closing a communication, and not speech playback. Nine missing-clip warnings were in the long voice path. `sounds/en_US` was absent.

Status words: `configuration-verified` means a generated file or derived arithmetic on that file was checked. It is not SvxLink event timing. `software-proven` means a cloud test executed the named behavior. `operator-gate` needs a person and a procedure. `hardware-unverified` needs the radio, the running controller, or a measurement. `not-this-architecture` means the cited duty is conditional and this setting is a different function. The native page gate on `adda19c` showed complete HTML. It did not complete FCC gates, preset translation, or handler execution.

## What the page gate did and did not close

Installed `97077d5` ran the native process through one long CW identification and one short CW identification, then stopped clean. svxlink was left inactive, unmasked, and disabled. `remotetrx` and `svxreflector` stayed masked. That does not verify an end-of-communication identification, a decoded call sign, spoken English audio, or a transmitter unkey. Heather speech is not installed. These rows are not complete.
